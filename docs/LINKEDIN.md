Uma ocorrência rodoviária pode envolver várias ações ao mesmo tempo: apoio aos passageiros, atendimento mecânico e atualizações sobre o que já foi feito. Acompanhar esse andamento exige manter o contexto de cada caso.

Desenvolvi o Fluxo de Ocorrências para organizar essas informações em um painel. Para apresentar o projeto no meu portfólio, preparei a versão pública Rota Demo, com identidade própria e dados inteiramente sintéticos.

Uma decisão importante foi acompanhar dois tempos: o socorro aos passageiros pode ser concluído enquanto o atendimento mecânico continua. Cada ocorrência também tem um histórico de eventos, que permite consultar as atualizações ao longo do atendimento, inclusive após finalizar ou reabrir o registro.

Na parte técnica, usei HTML, CSS e JavaScript vanilla. Separei o acesso aos dados em uma camada Store, independente da interface, e nesta demonstração a persistência fica no próprio navegador, com localStorage.

Também incluí filtros, preenchimento automático a partir dos cadastros, importação e backup. A demonstração já abre com exemplos e pode ser restaurada para quem quiser explorar o fluxo.

Todos os nomes, veículos, placas, localidades e registros dessa versão foram inventados. É possível testar o projeto diretamente no navegador, sem integrações externas ou envio de mensagens.
